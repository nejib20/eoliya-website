================================================================================
                          PROCHAINES ÉTAPES
================================================================================

Pour mettre le projet en production (4-5 heures):

1. INSTALLER LES DÉPENDANCES (30 min)
   $ cd /Users/Nejib/eoliya-website
   $ make install

2. CONFIGURER LES VARIABLES D'ENVIRONNEMENT (30 min)

   Frontend:
   $ cd frontend
   $ cp .env.example .env.local
   # Éditer .env.local avec:
   # - NEXT_PUBLIC_STRAPI_URL
   # - GOOGLE_CALENDAR_* (Client ID, Secret, Refresh Token)
   # - OPENAI_API_KEY
   # - RESEND_API_KEY
   # - NEXT_PUBLIC_GA_ID

   Backend:
   $ cd ../backend
   $ cp .env.example .env
   $ make secrets  # Générer les secrets Strapi
   # Éditer .env avec les secrets générés

3. TESTER EN LOCAL (30 min)
   $ make docker-up
   # Frontend: http://localhost:3000
   # Backend: http://localhost:1337
   # Admin: http://localhost:1337/admin

   $ make type-check  # Vérifier TypeScript
   $ make lint        # Vérifier code

4. DÉPLOYER (1h)
   $ ./scripts/deploy-production.sh
   # Ou manuel:
   # - Backend → Railway (https://railway.app)
   # - Frontend → Vercel (https://vercel.com)

5. PEUPLER LE CONTENU (1-2h)
   - Se connecter au panel admin Strapi
   - Créer le premier utilisateur admin
   - Ajouter les services (3)
   - Ajouter les projets
   - Ajouter l'équipe
   - Publier les articles de blog (15 disponibles dans /docs/content/blog/)

6. FINALISER SEO (30 min)
   - Soumettre sitemap à Google Search Console
   - Vérifier meta tags
   - Configurer Google Analytics
