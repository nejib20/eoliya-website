📋 VARIABLES D'ENVIRONNEMENT REQUISES
================================================================================

GOOGLE CALENDAR (optionnel):
  GOOGLE_CLIENT_ID              OAuth Client ID
  GOOGLE_CLIENT_SECRET          OAuth Client Secret
  GOOGLE_REFRESH_TOKEN          Refresh token OAuth
  GOOGLE_CALENDAR_ID            ID du calendrier (default: primary)
  GOOGLE_REDIRECT_URI           URI de redirection OAuth

OPENAI (optionnel):
  OPENAI_API_KEY                Clé API OpenAI (sk-proj-xxx)

RESEND (optionnel):
  RESEND_API_KEY                Clé API Resend (re_xxx)
  RESEND_FROM_EMAIL             Email expéditeur vérifié
  CONTACT_EMAIL                 Email destinataire

RATE LIMITING:
  RATE_LIMIT_MAX                Nombre max de requêtes (default: 10)
  RATE_LIMIT_WINDOW             Fenêtre en ms (default: 60000)

APP CONFIG:
  NEXT_PUBLIC_SITE_URL          URL du site
  NODE_ENV                      Environnement (development/production)

================================================================================
🚀 DÉMARRAGE RAPIDE
================================================================================

1. Installation:
   cd frontend
   npm install

2. Configuration:
   cp .env.example .env.local
   nano .env.local  # Ajouter vos clés API

3. Setup Google (optionnel):
   npm run setup-google

4. Lancer le serveur:
   npm run dev

5. Tester:
   http://localhost:3000/demo-integrations
