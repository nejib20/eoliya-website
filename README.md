# EOLIYA Ingénierie - Site Web

Site web corporate pour EOLIYA Ingénierie, bureau d'études spécialisé dans l'ingénierie du bâtiment, le relamping LED et les luminaires sur mesure.

## Structure du projet

```
eoliya-website/
├── frontend/          # Application Next.js 14
├── backend/           # API Strapi v5
├── docs/              # Documentation projet
│   ├── design/        # Maquettes et charte graphique
│   ├── specs/         # Spécifications techniques
│   └── content/       # Contenus textuels
└── README.md
```

## Stack technique

- **Frontend** : Next.js 14 (App Router), React 18, Tailwind CSS, Framer Motion
- **Backend** : Strapi v5, PostgreSQL
- **Hébergement** : Vercel (frontend), Railway (backend)
- **Intégrations** : Google Calendar API, OpenAI GPT-4

## Services EOLIYA

1. **Conseil et Pilotage** - Accompagnement projets TCE
2. **Multi-services & Relamping** - Dépannage, remise aux normes, LED
3. **Luminaires sur mesure** - Conception et fabrication personnalisée
