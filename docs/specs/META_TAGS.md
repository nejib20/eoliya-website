## 2. Règles de Rédaction Meta Tags

### 2.1 Title Tag

**Règles:**
- Longueur optimale: 50-60 caractères (max 70)
- Format recommandé: `[Mot-clé principal] - [Complément] | [Marque]`
- Inclure mot-clé principal en début de titre
- Unique pour chaque page
- Éviter "home", "accueil" dans le title de la homepage
- Utiliser séparateurs: tiret `-` ou pipe `|`

**Exemples:**
- ✅ `Relamping LED Entreprise Paris - Audit & Installation | EOLIYA`
- ✅ `Bureau d'Études TCE Paris - Tous Corps d'État | EOLIYA`
- ❌ `Accueil - EOLIYA Ingénierie - Bureau d'études Paris`
- ❌ `Bienvenue sur le site de EOLIYA Ingénierie, votre bureau d'études`

### 2.2 Meta Description

**Règles:**
- Longueur optimale: 140-160 caractères (max 165)
- Phrase d'accroche + bénéfices + call-to-action
- Inclure mot-clé principal et secondaire
- Inciter au clic avec chiffres, bénéfices concrets
- Ajouter numéro de téléphone si pertinent
- Unique pour chaque page

**Formule gagnante:**
`[Service] [Localisation]: [Bénéfices]. [Preuve sociale/Chiffres]. [CTA] ☎ [Téléphone]`

**Exemples:**
- ✅ `Relamping LED professionnel: audit éclairage, installation LED et économies jusqu'à 75%. ROI 2-4 ans. Paris & Île-de-France. Devis gratuit ☎ 01-XX-XX-XX-XX`
- ❌ `EOLIYA propose des services de relamping LED pour les entreprises.`

### 2.3 Meta Keywords

**Note:** Peu utilisés par Google, mais gardés pour Bing et autres moteurs.

**Règles:**
- 5-10 mots-clés maximum
- Ordre décroissant d'importance
- Uniquement mots-clés pertinents pour la page
- Variantes et expressions longues traîne

**Exemple:**
```html
<meta name="keywords" content="relamping LED paris, audit éclairage LED, installation LED entreprise, économie énergie éclairage, luminaires LED professionnels">
```

## 3. Open Graph (Facebook, LinkedIn)

### 3.1 Propriétés Obligatoires

```html
<meta property="og:type" content="website|article">
<meta property="og:url" content="[URL complète de la page]">
<meta property="og:title" content="[Titre optimisé partage social]">
<meta property="og:description" content="[Description engageante]">
<meta property="og:image" content="[URL image 1200x630px]">
```

### 3.2 Spécifications Images OG

**Dimensions recommandées:**
- Format: 1200 x 630 pixels (ratio 1.91:1)
- Format alternatif: 1200 x 1200 pixels (carré)
- Poids: < 5 MB
- Formats: JPG, PNG, WebP
- Résolution: 72 dpi minimum

**Bonnes pratiques:**
- Texte lisible même en petit format
- Logo visible mais pas trop imposant
- Visuels de qualité professionnelle
- Éviter texte > 20% de l'image (règle Facebook)

### 3.3 Open Graph Article (pour blog)


## 5. Canonical URLs Strategy

### 5.1 Principe

La balise canonical indique à Google quelle est la version principale d'une page quand plusieurs URLs affichent le même contenu (ou similaire).

### 5.2 Règles d'Implémentation

**1. Canonical auto-référentiel sur toutes les pages:**

```html
<link rel="canonical" href="https://eoliya.com/services/conseil-tce">
```

**2. Toujours utiliser l'URL complète (absolue):**

```html
✅ <link rel="canonical" href="https://eoliya.com/page">
❌ <link rel="canonical" href="/page">
```

**3. Utiliser HTTPS (jamais HTTP):**

```html
✅ <link rel="canonical" href="https://eoliya.com/page">
❌ <link rel="canonical" href="http://eoliya.com/page">
```

**4. Pas de trailing slash inconsistant:**

Choisir une convention et s'y tenir:
```html
Option A: https://eoliya.com/services (sans slash)
Option B: https://eoliya.com/services/ (avec slash)
```

**Recommandation:** Sans trailing slash pour cohérence avec Next.js.

### 5.3 Cas d'Usage Canonical

#### Pagination (si applicable)

**Page liste blog avec pagination:**
```html
<!-- Page 1 (canonique) -->
<link rel="canonical" href="https://eoliya.com/blog">

<!-- Page 2 (pointe vers page 2, pas page 1) -->
<link rel="canonical" href="https://eoliya.com/blog?page=2">
<link rel="prev" href="https://eoliya.com/blog">
<link rel="next" href="https://eoliya.com/blog?page=3">
```

#### Paramètres URL (tracking, filtres)

**URL avec paramètres tracking:**
```
URL visitée: https://eoliya.com/services/relamping-led?utm_source=google&utm_campaign=led
Canonical: https://eoliya.com/services/relamping-led
```

```html
<link rel="canonical" href="https://eoliya.com/services/relamping-led">
```

#### Variantes mobile (si site mobile séparé)

**Si site mobile séparé (non recommandé, préférer responsive):**
```html
<!-- Version desktop -->
<link rel="canonical" href="https://eoliya.com/services/tce">
<link rel="alternate" media="only screen and (max-width: 640px)" href="https://m.eoliya.com/services/tce">

<!-- Version mobile -->
<link rel="canonical" href="https://eoliya.com/services/tce">
```

**Note:** Avec Next.js responsive, ce cas ne s'applique pas.
