## 🚀 GUIDE D'UTILISATION

### 1. Consultation des contenus
Tous les fichiers sont au format **Markdown (.md)** :
- Lisibles dans n'importe quel éditeur de texte
- Prévisualisables dans VS Code, GitHub, etc.
- Facilement convertibles en HTML

### 2. Intégration dans un CMS

#### WordPress
- Copier/coller le contenu dans l'éditeur Gutenberg ou Classic
- Utiliser les titres (##, ###) comme hiérarchie de blocs
- Ajouter les métadonnées SEO via Yoast ou Rank Math

#### Webflow, Wix, Squarespace
- Copier/coller section par section
- Adapter la mise en forme selon le builder

#### Développement custom (React, Next.js, etc.)
- Parser directement les fichiers Markdown
- Utiliser un convertisseur MD → HTML (remark, marked, etc.)
- Intégrer les métadonnées SEO dans les composants

### 3. Structure des fichiers

Chaque fichier contient :
```markdown
# Titre principal

**Catégorie :** [Catégorie]
**Date :** [Date]
**Temps de lecture :** X min

## Section 1
Contenu...

## Section 2
Contenu...

---

## SEO - Métadonnées

**Title :** ...
**Meta description :** ...
**Mots-clés ciblés :** ...
```

### 4. Personnalisation

Les contenus sont **prêts à l'emploi** mais peuvent être adaptés :
- Ajuster le ton selon votre préférence
- Ajouter des exemples clients spécifiques
- Enrichir avec des données chiffrées propres à EOLIYA
- Traduire en anglais ou autres langues si besoin
