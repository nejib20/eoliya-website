🚀 DÉMARRAGE RAPIDE (5 minutes)
═══════════════════════════════════════════════════════════════════════════

1️⃣ Installer les dépendances
   cd frontend
   npm install

2️⃣ Configurer les variables d'environnement
   cp .env.example .env.local
   
   Éditer .env.local et ajouter AU MINIMUM:
   OPENAI_API_KEY=sk-proj-xxx  (pour le chatbot)
   
   Les autres intégrations sont optionnelles !

3️⃣ Lancer le serveur
   npm run dev

4️⃣ Tester
   Ouvrir: http://localhost:3000/demo-integrations

🔐 VARIABLES D'ENVIRONNEMENT
═══════════════════════════════════════════════════════════════════════════

Configuration MINIMALE (juste le chatbot):

Configuration COMPLÈTE (toutes les intégrations):
   
   # OpenAI Chatbot
   OPENAI_API_KEY=sk-proj-xxxxxxxxxxxxx
   
   # Resend Emails
   RESEND_API_KEY=re_xxxxxxxxxxxxx
   RESEND_FROM_EMAIL=contact@eoliya.com
   CONTACT_EMAIL=contact@eoliya.com
   
   # Google Calendar (le plus complexe)
   GOOGLE_CLIENT_ID=xxx.apps.googleusercontent.com
   GOOGLE_CLIENT_SECRET=xxx
   GOOGLE_REFRESH_TOKEN=1//xxx
   GOOGLE_CALENDAR_ID=primary
   
   # Rate Limiting
   RATE_LIMIT_MAX=10
   RATE_LIMIT_WINDOW=60000

🐛 PROBLÈMES COURANTS
═══════════════════════════════════════════════════════════════════════════

❌ "Module not found"
   → rm -rf node_modules && npm install

❌ Chatbot ne répond pas
   → Vérifier OPENAI_API_KEY (doit commencer par "sk-proj-")
   → Vérifier les logs du serveur

❌ Emails non reçus
   → En dev, utiliser RESEND_FROM_EMAIL=onboarding@resend.dev
   → Vérifier le dossier spam

❌ Google Calendar erreur credentials
   → Relancer: npm run setup-google
   → Vérifier que le redirect URI correspond
