## Recommandations

### Actions Immédiates (Avant Déploiement)

1. **Installation des dépendances**
   ```bash
   make install
   ```

2. **Configuration des variables d'environnement**
   - Frontend: Copier `.env.example` → `.env.local`
   - Backend: Copier `.env.example` → `.env`
   - Générer secrets Strapi: `make secrets`
   - Configurer clés API (Google, OpenAI, Resend)

3. **Tests locaux**
   ```bash
   make docker-up
   make type-check
   make lint
   ```

### Déploiement

**Méthode Recommandée:**
```bash
./scripts/deploy-production.sh
```

**Services:**
- **Frontend:** Vercel (Next.js)
- **Backend:** Railway (Strapi + PostgreSQL)

### Post-Déploiement

1. Vérifier santé des services
2. Configurer domaine personnalisé
3. Peupler contenu Strapi
4. Soumettre sitemap à Google
5. Configurer monitoring
