## 🎓 Apprentissages Clés

### Ce qui fonctionne bien
1. **Multi-layer overlays** créent une vraie profondeur
2. **Parallax subtil** (150px) est plus élégant que agressif
3. **Glassmorphism** ajoute instantanément du premium
4. **Text shadows doubles** (profondeur + glow) sont percutants
5. **Auto-rotation 6s** est le sweet spot (ni trop rapide, ni lent)

### Pièges évités
1. ❌ Parallax trop prononcé (motion sickness)
2. ❌ Trop d'animations simultanées (distraction)
3. ❌ Images non-optimisées (slow LCP)
4. ❌ Overlay trop opaque (cache les images)
5. ❌ Text trop petit sur mobile (lisibilité)

## 📞 Support

### Questions Fréquentes

**Q: Puis-je changer les images ?**
A: Oui, modifiez le tableau `HERO_IMAGES` dans le composant.

**Q: Comment désactiver l'auto-rotation ?**
A: Commentez le `useEffect` qui contient `setInterval`.

**Q: Le parallax fonctionne sur mobile ?**
A: Oui, mais peut être désactivé si `prefers-reduced-motion`.

**Q: Puis-je utiliser des images locales ?**
A: Oui, remplacez les URLs Unsplash par `/images/...`.

**Q: Comment changer les couleurs ?**
A: Modifiez les classes Tailwind `primary-*`, `secondary-*`, `accent-*`.
